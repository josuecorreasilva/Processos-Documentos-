# Painel — Compras, empenhos e registros (SMS / Atenção Primária)

Painel estático do acervo de Registros de Preços (RP02–RP13) e dos **Processos O2** (dispensa + pregão).

## Abrir no celular

Use o link publicado do app (Cursor Publish) ou sirva a pasta:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Depois abra `#registros` para ver RP e O2.
